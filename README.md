# Caminatas

Identifica las caminatas que haces cada día y las calorías que quemas en cada una, a partir del export de **Simple Health Export CSV** del iPhone.

Todo se procesa en tu navegador: tus datos de salud no se suben a ningún servidor.

## Estado

En migración de una app de escritorio en Python a una web estática.

- `version-python/`: la app original (PySide6). Sirve como referencia para las pruebas de la versión web.

## Cómo usar la versión Python

```
python3 version-python/main.py
```

Arrastra la carpeta del export (descomprimida) a la ventana o usa el botón para elegirla.
